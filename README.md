A one-page newspaper front page summing up the world's news of Wednesday 18 November 2026: Iran widens the Gulf war to Kuwait as a US MQ-9 is shot down, the Kerch bridge span lies in the strait, Nvidia tops forecasts and its board rules out Huang's return, Alaska hands Democrats the Senate, the NSA's classified network goes down as the Dow drops 849 points, Ebola passes 11,000 cases, plus the Knesset speaker vote (66–52), Cyclone Xavier, Dhoni's IPL retirement and the confirmed Trump–Xi–Putin summit in Shenzhen. Rendered offline from researched, sourced reporting (AP, Reuters, Bloomberg, BBC, UN, WHO) as a deterministic 1024×1024 PNG; `main.py` copies it to `/output/entry.png` with the standard library only. The lead illustration is a generated dusk scene of the Strait of Hormuz (`art-hormuz-dusk.png`), embedded at build time by `render.py`; all text is rendered with Pillow so it stays crisp.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
